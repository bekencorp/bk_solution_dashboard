Project Description
-------------------

  - Under the two-wheeled vehicle solution, three different resolution LCDs have been adapted, namely 480x272, 800x480, and 1024x600 LCDs. Each resolution corresponds to a separate demo project. Projects with V2 suffix in the project name are adapted for the two-wheeled vehicle solution V2 development board, while others default to using the V1 development board.

  - When using mobile app for testing different demo projects, the mobile app configuration is as follows:

    1. scooter_480_272:
