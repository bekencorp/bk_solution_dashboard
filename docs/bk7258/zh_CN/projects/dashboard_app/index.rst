dashboard app使用指南
=======================================


:link_to_translation:`en:[English]`

1 下载
------------------

扫描二维码，下载安装。

.. figure:: ../../../_static/dashboard_app/download_qr_code.png
   :alt: downlaod_qr_code
   :width: 30%
   
   下载二维码

2 简介
------------------
通过此app,让开发板播放导航语音，显示导航图片。根据图传方式的不同，分为蓝牙图传和wifi图传。

3. 开发板介绍
-----------------------

以如下开发板举例。

- reset 按键：复位开发板
- k1按键: 清除配网信息并复位开发板

.. figure:: ../../../_static/dashboard_app/board.png
   :alt: board

   示例开发板
