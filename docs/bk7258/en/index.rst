Beken BK7258 Two-Wheeler Solution
=====================================

:link_to_translation:`zh_CN:[中文]`

	This is the official documentation for the Beken BK7258 Two-Wheeler Solution development framework.

	The solution is built on the **BK7258** SoC and the **BK3515NS** Bluetooth companion, and depends on **BK AVDK SMP (Armino SMP SDK)**. It targets dashboard screens of various resolutions and provides LVGL display plus complete end-to-end reference projects.

	For BK AVDK SMP documentation, see `Armino SMP (English) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/en/v3.1.1/index.html>`_ or `Armino SMP (中文) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/zh_CN/v3.1.1/index.html>`_.
