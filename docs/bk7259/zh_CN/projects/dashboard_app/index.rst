2 简介
------------------
通过此app,让开发板播放导航语音，显示导航图片。根据图传方式的不同，分为蓝牙图传和wifi图传。

3. 开发板介绍
-----------------------

以如下开发板举例。

- reset 按键：复位开发板
- 长按下键: 清除配网信息并复位开发板

.. figure:: ../../../_static/dashboard_app/dashboard_v1.jpg
   :alt: board
   :width: 30%

   示例开发板


4. WIFI图传使用步骤
-----------------------

通过wifi传输图片,通过经典蓝牙传输语音。


4.1 重置开发板
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

长按下键，重置开发板。


4.2 配置
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

根据需要选择配置，注意宽度和高度需要配成与开发板屏幕尺寸一致。

   配置中心

,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,
